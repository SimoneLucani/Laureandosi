# University Graduation Prospectus Management System

A web-based application developed for the Software Engineering (Ingegneria del Software) exam at the University of Pisa. This project encompasses the entire software engineering lifecycle, from formal UML architectural design to PHP implementation.

## Overview
The system automates and streamlines the graduation workflow for the university's teaching unit:
* **Prospectus Generation:** Allows the teaching unit to create official graduation prospectuses for candidates.
* **Automated Verification:** Sends the prospectuses to graduating students via email for data review and verification.
* **Committee Evaluation:** Provides a dedicated interface for the graduation committee to assess candidate profiles and determine the final graduation grade.

## Core Stack & Methodology
* **Software Design:** Full UML modeling (Use Case, Class, and Sequence Diagrams).
* **Backend:** PHP.
* **Frontend:** HTML, CSS.
